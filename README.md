# Story Generator
Generates a text story based on user specifications. 

## Setup
1. Clone this GitHub Repository 
2. Get API key from [Google AI Studio](https://aistudio.google.com/)
3. Naviagate to "CS3560_Assignment3_StoryGenerator\src\main\java\api\APIClient.java", copy and paste your API key inside the quotes where it says "INSERT_YOUR_API_KEY_HERE"
4. Navigate to "CS3560_Assignment3_StoryGenerator\src\main\java\main\Main.java" and run Main.java

## Features
* Reading level selection (e.g. child, teen, adult)
* Story length customization
* Save and load stories to Story Library
* Add chapters to existing stories

## Design Patterns
* Strategy: Different reading level options
* Factory: Prompt modification 
* Observer: Content curation
* Singleton: APIClient
